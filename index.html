PROYECTO 01 / WEB & MOBILE

Sistema de Gestión de Equipos Médicos

Plataforma para apoyar el control de equipos, el registro de reportes y el seguimiento de procesos de mantenimiento. La solución conecta una aplicación Flutter con un backend Laravel mediante una API REST y una base de datos MySQL.
