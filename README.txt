PORTAFOLIO WEB - NEXUS / DESARROLLO DE SOFTWARE

ARCHIVOS
- index.html: contenido y estructura.
- styles.css: diseño, colores, responsive y animaciones.
- script.js: menú móvil, animaciones al desplazarse y ampliación de imágenes.
- images/: las dos capturas que compartiste.

ABRIR EN VISUAL STUDIO CODE
1. Descomprime portafolio_nexus.zip en una carpeta de tu PC.
2. Abre Visual Studio Code.
3. File > Open Folder y selecciona la carpeta portafolio_nexus.
4. Abre index.html.
5. Instala la extensión Live Server (Ritwick Dey) desde Extensions.
6. Clic derecho en index.html > Open with Live Server.
   Si no quieres instalar extensión, también puedes abrir index.html directamente en Chrome.

PERSONALIZAR ANTES DE PUBLICAR
- En index.html busca "TU_CORREO@ejemplo.com" y reemplázalo por tu correo.
- Completa nombre profesional y enlaces de LinkedIn/GitHub cuando los confirmemos.
- Revisa cada tecnología y función: deja solo lo que puedas explicar en entrevista.
- Las barras de habilidades son ilustrativas; si no te gustan, las quitamos o reemplazamos por etiquetas sin porcentajes.

GITHUB: QUÉ PUBLICAR
Puedes publicar este portafolio web en un repositorio público.
No subas el código fuente completo del sistema del hospital, archivos .env, contraseñas, tokens, dumps SQL, datos reales de usuarios/pacientes ni información confidencial.
Si más adelante quieres mostrar código del proyecto, prepara un repositorio separado y saneado: solo módulos propios que tengas autorización para compartir, datos ficticios y README. Nunca publiques credenciales ni bases reales.

GITHUB PAGES
1. Crea/inicia sesión en https://github.com/
2. New repository > nombre: portafolio > Public.
3. Sube index.html, styles.css, script.js y la carpeta images.
4. Settings > Pages > Deploy from a branch.
5. Branch: main; folder: /(root); Save.
6. Espera el despliegue y copia la URL que GitHub Pages muestra.

NOTA
